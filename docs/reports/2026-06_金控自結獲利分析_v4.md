# 2026年6月金控自結獲利策略報告｜v4

## 一、第二季股市大漲，但金控獲利沒有同步普遍上升

截至本報告資料截點，13家金控均已公告6月自結獲利，公告完整度為13／13，本報告不是暫定版本。13家金控6月單月獲利合計約734.9億元，較5月約759億元減少約3.2%。

第二季台股漲幅顯著：4月上漲22.71%、5月上漲14.92%、6月上漲3.11%，第二季累計上漲45.40%；S&P 500同期上漲14.86%。如此強勁的股票行情，理論上有利壽險股票投資及券商資本市場業務，但實際成果會因金融資產分類、期間內買賣、避險調整及獲利實現位置而不同。

本期重點如下：

1. 國泰金6月獲利165.9億元，單月金額居首；元大金與國泰金若以6月獲利除以1Q期末淨值年化，分別約25.1%及24.6%，規模校正後仍居主要金控前列。
2. 國泰人壽6月P&L為113.7億元、月增27.3%，是四家壽險型金控中最高；富邦及凱基人壽的P&L較低，但加計FVOCI權益處分後分別為197.8億元及154.5億元，投資成果有相當部分未進入當期P&L。
3. 銀行子公司合計月增4.2%，但中國信託銀行月減30.0%、金額減少約18.1億元，壓低整體增幅；現有資料不足以指定單一原因。
4. 券商合計獲利月增7.6%，方向與集中市場成交額月增5.1%一致；但排除凱基證券後，其餘券商合計反而月減約4.0%，產業增長並不廣泛。

## 五、證券：整體與量價同向，但增長集中於凱基

6月台股集中市場日均成交額13,839億元、月增5.10%，加權指數上漲3.11%。成交額口徑只含集中市場，未涵蓋上櫃、期貨及選擇權。有單月數字的券商合計獲利由約172.3億元增至約185.5億元、月增7.6%；排除凱基證券後，其餘券商合計反而月減約4.0%。合計數涵蓋所有已揭露單月數字的證券子公司，下表只列規模較大的九家，因此表列金額加總低於合計數。

經紀市占率長期排序為元大約15%、凱基約11%、富邦約7%，排名通常穩定，個別月份小幅變動。市占率是經紀規模參考，不足以單獨解釋券商稅後獲利。

1Q26法說顯示，元大、凱基及富邦證券的經紀收入占比相近，分別約56.9%、57.1%及58.6%，但投資、交易及其他金融收益占比分別約26.0%、35.0%及24.2%。這是1Q已揭露的收入結構事實，說明三家券商的非經紀部位權重本就不同；在取得6月業務別資料前，不以此推算任何一家的非經紀獲利金額。

**獲利品質：**凱基、富邦及國泰證券本月的超額增幅，在1Q收入結構中對應的是投資與交易項目，屬**資本市場敏感**；經紀部分屬**經常性**，但兩者的6月拆分尚未揭露，無法量化。
