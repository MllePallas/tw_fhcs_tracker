# 2026年7月金控自結獲利策略報告

## 一、7月台股回檔，資本市場敏感的金控全數回落，富邦金單月轉為虧損

截至本報告資料截點（tracker最後更新2026年8月14日），13家金控中有11家已公告7月自結獲利，公告完整度為11／13；第一金與合庫金尚未公告，合庫金最新資料仍停留在5月。公告家數已達10家門檻，本報告不標示為暫定，但所有合計數與排序均只涵蓋這11家。

已公告11家7月單月獲利合計約460.7億元，較同一組公司6月合計約683.1億元減少約32.6%；排除富邦金後，其餘10家合計仍月減約18.7%。

7月市場行情由漲轉跌：台股加權指數由46,125.91點跌至43,119.75點，月跌6.52%；S&P 500下跌0.13%；美國10年期公債殖利率由4.418%升至4.745%，上升33bps；美元兌台幣由31.8659升至32.395，台幣貶值1.66%。股跌、債券殖利率上升、台幣貶值三個方向同時出現，理論上不利股票部位與債券評價、有利未完全避險之外幣資產換算，但實際成果會因金融資產分類、期間內買賣、避險調整及獲利實現位置而不同。

本期重點如下：

1. 富邦金7月單月稅後虧損17.6億元，是11家中唯一單月虧損者；虧損集中於富邦人壽的-76.6億元，台北富邦銀行與富邦證券當月仍為正數但不足以抵銷。
2. 國泰人壽7月P&L由113.7億元降至54.2億元、月減52.3%；新光人壽反向月增18.7%至57.7億元，是四家壽險中唯一單月增加者，也是7月P&L最高者。
3. 銀行子公司可比七家合計月減4.4%，明顯優於金控整體；兆豐銀行單月42.1億元、月增55.4%，是唯一大幅增加者，排除後其餘六家合計月減11.0%。
4. 券商可比八家合計月減41.4%，遠大於集中市場日均成交額月減24.7%；但排除凱基證券後合計月減22.7%，與成交額跌幅接近——凱基證券由6月的50.3億元降至7.2億元，6月的超額幾乎全數回吐。

**獲利品質：**國泰、凱基與富邦人壽7月P&L的變動方向與台股、殖利率的不利方向一致，屬**資本市場敏感**；新光人壽的反向增加與台灣人壽均缺乏可歸類的揭露，**不足以歸類**。保險本業貢獻仍須待2Q法說的保險服務結果揭露後才能歸入經常性。

## 五、證券：合計跌幅遠大於成交量，但幾乎全部來自凱基證券
